FOREST RUNNER - Unity 6.3 (2D)
1. Unity Hub > New project > "2D (Built-In Render Pipeline)" or "Universal 2D", Unity 6.3.
2. Close Unity, copy this folder's "Assets" contents into your project's Assets folder (merge), reopen.
3. Open Assets/Scenes/Main.unity and press Play. (It also boots in any scene, even SampleScene.)
Controls: Space / Up / W / Click / Tap = jump (double jump). P or Esc = pause.
No sprites, prefabs, tags or layers are needed - everything is generated in code.
Works with both Input System and legacy Input Manager. Build: File > Build Profiles > Android/iOS.
